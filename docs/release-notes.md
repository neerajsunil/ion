Ion for Windows 11 (x64): the lightweight IDE for coding with AI agents.

**Download** `ion-<version>-windows-x64.zip`, extract it anywhere and run
`ion.exe`, or download the `.exe` on its own. It's a single portable file
with no installer.

Ion is in early development and the build isn't code-signed yet, so Windows
SmartScreen may warn on first launch: choose **More info → Run anyway**.
Checksums are in `SHA256SUMS`.

SSH remote projects need the Windows **OpenSSH Client** optional feature.

What's new: see [CHANGELOG.md](https://github.com/neerajsunil/ion/blob/main/CHANGELOG.md).
