Ion for Windows 11 (x64) and macOS (Apple Silicon): the lightweight IDE for
coding with AI agents.

**Windows:** download `ion-<version>-windows-x64.zip`, extract it anywhere and
run `ion.exe`, or download the `.exe` on its own. It's a single portable file
with no installer.

**macOS 12+:** download `ion-<version>-macos-arm64.zip`, unzip it and drag
`Ion.app` to Applications.

Ion is in early development and the builds aren't code-signed yet. On Windows,
SmartScreen may warn on first launch: choose **More info → Run anyway**. On
macOS, open Ion once, then choose **System Settings → Privacy & Security →
Open Anyway**. Checksums are in `SHA256SUMS`.

SSH remote projects need the Windows **OpenSSH Client** optional feature.

What's new: see [CHANGELOG.md](https://github.com/neerajsunil/ion/blob/main/CHANGELOG.md).
